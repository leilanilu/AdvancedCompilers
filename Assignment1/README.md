## Overview
This project adds two new LLVM passes to the llvm-tutor framework:

1. *SimpleLICM.cpp* – LICM pass. 
   - Implemented worklist algorithm

2. *DerivedInductionVar.cpp* – an Induction Variable (IV) analysis and elimination pass.  
   - Identify induction variables in inner and outer loops
   - Eliminated indution variables

Source files located in llvm-tutor/lib
